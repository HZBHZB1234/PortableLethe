## 3. 假设与边界说明

1. **"Hub 不调 C#"** 解释为：Hub 进程内不依赖 .NET 运行时、不做 C# interop；调用 `dotnet publish` 命令行属于外部工具链，用户已确认允许。
2. **"静态数据永不嵌入"** 实际发布形态为 exe + 同级 `data/` + `static/` 目录，不是真·单文件；已按此设计。
3. **客户端发布包** 不含游戏本体/Steam 文件、不含 Addressables bundle、不含 ZylarNex；含预编译 launcher、BepInEx 私服基线、配置模板与 modfiles。
4. **私服 profile** 以 `LetheLauncher-Distribution-7/` 为基线（Lethe.dll + ModularSkillScripts.dll + motions.dll + BepInEx core/doorstop/dotnet + Lethe.cfg）。
5. **登录 token 形状**：需包含 `sub`/`name`/`avatar`；`name` 可为用户名，`avatar` 可为占位值。
6. **静态数据更新生效**：因服务端静态字段缓存，更新后必须重启；Hub 自动触发。

3. bundle 差异同步的 v1 范围：是否首版就做（计划中排在 P6.5，可后置）。
4. 版本兼容矩阵：Launcher profile 的 `serverVersion` 与服务端协议版本的对应关系，需在 T7.2/T8.1 中记录。
